# 讀懂日曆價差｜期權研究室

繁體中文互動文獻導讀，以動畫、圖表、試算及小測驗解釋日曆價差期權的原理與四篇相關研究。

網站：https://porscheyeung.github.io/calendar-spread-lab/

純前端，直接開啟 index.html 即可使用，不需要安裝套件，不收集或上傳使用者資料。

所有試算與虛構情境只作教學，不是真實期權報價或歷史回測，不構成投資建議。各篇文獻的閱讀深度、研究限制及原始來源均列於網頁內。

GitHub Pages 使用 main 分支根目錄發布。
